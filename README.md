# 📦 SiteBox-Landing-Page

[![Live Demo](https://shields.io)](https://vercel.app)
[![Built with Vite](https://shields.io)](https://vitejs.dev)
[![React](https://shields.io)](https://react.dev)
[![Framer Motion](https://shields.io)](https://framer.com)

A premium, production-ready React landing page built for **SiteBox**. This interface blends ultra-modern aesthetic design tokens inspired by industry giants like Vercel and Stripe with fluid, physics-based micro-interactions. Optimized for sub-second page loads and seamless multi-device scaling.

🔗 **Live Deployment:** [site-box.vercel.app](https://vercel.app)

---

## ✨ Features

- **⚡ Blazing Fast Bundling:** Powered by Vite for near-instantaneous Hot Module Replacement (HMR) and optimized rollup production assets.
- **✨ Fluid Micro-Interactions:** Utilizes Framer Motion to drive context-aware entrance transitions, scroll-linked typography elevations, and physics-based button magnetic fields.
- **🎨 Premium Design Tokens:** Implements strict layout grids, minimalist dark/light borders, high-contrast monochrome accent tokens, and sleek glassmorphism panels inspired by premium SaaS visual design languages.
- **📱 Fully Responsive Typography & Layouts:** Fluid spacing structures ensuring dynamic readability transitions across mobile, tablet, and ultra-wide monitor breakpoints.

---

## 🛠️ Tech Stack

- **Framework Core:** React 18
- **Build Pipeline & Server:** Vite
- **Animation System:** Framer Motion
- **Styling Architecture:** Custom CSS Utilities / Design Token Systems

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) installed on your machine.

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd SiteBox-Landing-Page
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Spin up the local development server:**
   ```bash
   npm run dev
   ```
   *Your terminal will display the local address (typically `http://localhost:5173/`).*

---

## 📦 Production Deployment

To generate an optimized, tree-shaken static production build ready for host environments like Vercel or Netlify:

```bash
npm run build
```

The output build assets will be compiled inside the `/dist` directory.
